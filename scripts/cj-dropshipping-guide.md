# CJ Dropshipping 注册指南 — ShopEasy 一件代发

## 注册步骤

### 1. 打开注册页面
访问: https://www.cjdropshipping.com/
点击右上角 "Sign Up" / "注册"

### 2. 填写信息
- Email: 使用一个新邮箱（建议专门给 ShopEasy 用）
- Password: 设置密码
- Store Name: ShopEasy
- Store URL: https://shop2026easy.com
- Select Platform: 选 "Other/独立站"

### 3. 验证邮箱
CJ 会发验证邮件，点击链接激活

### 4. 绑定 PayPal 收款
在 CJ 后台绑定您的 PayPal 账号（和 ShopEasy 同一个），方便付款进货

---

## 选品流程（注册后）

1. 登录 CJ → 进入 "Product Center" / "产品中心"
2. 搜索关键词: Bluetooth headphones, smart watch, drone, blender 等
3. 筛选条件:
   - 勾选 "Fast Shipping"（快速发货）
   - 选择 "US Warehouse" 或 "EU Warehouse"（发货更快）
   - 价格筛选 $5-$50（加价卖到 $20-$150）

4. 把产品 "Add to My Products" 添加到您的产品库

5. 在 CJ 产品页面找到产品图片，右键保存
   → 用于替换 ShopEasy 上的 placeholder 图片

---

## 处理订单流程

1. 客户在 ShopEasy.com 下单付款 → 收到 Formspree 邮件通知
2. 登录 CJ 后台 → "Order" → "Add Order"
3. 填入客户姓名、地址、产品信息
4. CJ 处理发货（通常 1-2 天出物流单号）
5. 把物流单号发给客户
6. 在 ShopEasy 的 order-history.html 中手动更新物流信息

---

## 物流时效参考（CJ Dropshipping）
- 中国直发: 7-15 个工作日（欧美）
- US Warehouse: 3-7 个工作日
- EU Warehouse: 3-7 个工作日
- 费用: 约 $3-$8/单（小包）
